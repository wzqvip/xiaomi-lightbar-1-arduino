说明

    

      这个页面用 Web Serial 直接对 Arduino 的 optiboot 讲 STK500 协议，
      写入后还会逐页回读校验。和 pio run -t upload 做的事一样，只是不需要装工具链。


      需要桌面版 Chrome / Edge / Opera，以及 HTTPS 或 localhost（file:// 也算安全上下文）。

      如果是直接双击本文件打开的：浏览器会禁止 fetch 本地文件，
      所以读不到内置固件 —— 这时候手动选一个 .hex 就行
      （自己编译的在 .pio/build/nanoatmega328/firmware.hex）。
      部署到 GitHub Pages 或走 localhost 就能自动加载。
